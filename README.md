
# Sales Forecasting Dashboard

## Project Overview
This Power BI dashboard analyzes sales performance using historical retail data.

## Key Metrics
- Total Sales
- Total Profit
- Total Quantity Sold
- Average Discount

## Visualizations
- Category Sales Analysis
- Regional Profit Analysis
- Sales Distribution by Segment
- Top States by Sales

## Tools Used
- Power BI
- Excel / CSV Dataset
